Ubuntu / Linux Terminal Commands

Copy & paste directly into your Ubuntu terminal or SSH session

1. Launch Interactive Remote Terminal Shell (Recommended): 
python3 run.py -u recv "?token={{ token }}"
2. Pull Entire Folder directly via Curl & Tar (No Python required): 
curl -sL "/api/tar?path={{ current_path }}&token={{ token }}" | tar -xz

wget -O {{ shared_name }}.tar.gz "/api/tar?path={{ current_path }}&token={{ token }}" && tar -xzf {{ shared_name }}.tar.gz
